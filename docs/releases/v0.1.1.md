# v0.1.1 - Start with a reproducible demo

Codex Engineering Kit adapts ECC engineering guidance into a native Codex plugin and project-scoped roles: **350 skills and migrated commands, 71 specialist role templates**.

## New in this release

- A task-first README with installation steps, troubleshooting, compatibility boundaries and a concrete first-run prompt.
- A self-contained synthetic order-totals demo: the same eight tests expose two expected failures in a faulty fixture and pass against the corrected example.
- A guide for requesting a delegated test/review workflow in Codex. The standalone demo itself does not invoke a model or launch agents.
- Contributor guidance and demo execution in Linux/macOS CI.

## Try it

Python 3.11+; no third-party packages needed for the demo:

```sh
git clone --branch v0.1.1 --depth 1 https://github.com/DennisResponsa/codex-engineering-kit.git
cd codex-engineering-kit
python3 examples/order_totals/run_demo.py
```

Or extract the attached `codex-engineering-kit-v0.1.1.zip`, enter its directory and run the same Python command. Verify the archive against `SHA256SUMS.txt` if desired.

Expected: BEFORE has two failures; AFTER passes all eight tests; `demonstration_verified` is true and the command exits 0. The initial failures are deliberate, not a failed installation.
