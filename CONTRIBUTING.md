# Contributing

Start with a reproducible issue or a small pull request. Useful contributions include clearer installation instructions, compatibility reports, synthetic demos and fixes with focused tests.

- Use only data and code you can publish. Never include customer projects, credentials, local configuration or private logs.
- Follow AGENTS.md. Keep the upstream snapshot unchanged; edit the adapter builder and regenerate when changing generated entries.
- Describe the problem, expected behavior, observed result and exact checks performed. Do not claim all skills work because the catalog loads.
- Run the validation commands in README.md, including the synthetic demo. Record which Codex version was used if reporting native discovery.
- Preserve MIT attribution and state external dependencies honestly.

For agent workflows, distinguish the author from the reviewer. Installing this kit does not authorize model switches, external actions or publication.
